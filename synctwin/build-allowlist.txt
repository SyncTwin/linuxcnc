# SyncTwin fork build allowlist — the ONE list of what the linuxcnc-uspace package carries.
# Readers: src/Makefile (rt/kins: only these realtime modules are built and installed),
#          debian/configure (bin/path: writes debian/linuxcnc-uspace.install from this file).
# Machine-readable for the printers: every `loadrt X` they print must be an `rt`/`kins` line here,
# or an out-of-tree component built on the VM by halcompile (st_cia402, shaper, port_env, plant, iec_*, lcec — not
# this package). The -dev package keeps debian/linuxcnc-uspace-dev.install (halcompile, headers) as is.
#
# Format: one entry per line, `<kind> <name> [<dest>]`, `#` starts a comment.
#   rt   <module>        realtime module /usr/lib/linuxcnc/modules/<module>.so
#   kins <module>        kinematics module, same place (own kind so a printer can tell [KINS]KINEMATICS apart)
#   bin  <name>          /usr/bin/<name>
#   path <src> [<dest>]  any other installed path, as a dh_install line
# A name absent from the fork's obj-m is a build error (src/Makefile), not a silent skip.
